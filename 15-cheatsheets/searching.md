# Searching

## Search text

rg "AsyncStorage"

## Search in TSX only

rg "AsyncStorage" -g "*.tsx"

## Search case-insensitive

rg -i "expo"

## Search hidden files

rg "TODO" --hidden

## Find file

find . -name "package.json"

## Why is package installed?

pnpm why expo-image

## Current directory

pwd

## List files

ls
