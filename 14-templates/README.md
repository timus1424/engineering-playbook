# Engineering Playbook

This repository is my personal engineering knowledge base.

It is **not** a collection of tutorials.

Everything here is either:

- something I learned the hard way
- something I keep forgetting
- a workflow I want to reuse
- a mistake I don't want to repeat
- a checklist for future projects
- reusable templates or snippets

If I can easily Google it, it probably doesn't belong here.

The goal is simple:

> Make Future Timus a better engineer than Present Timus.
